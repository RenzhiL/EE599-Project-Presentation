\begin{frame}{Conclusions}
  \begin{itemize}
    \item \textbf{A mapping benchmark and one shared environment:} 24 circuits with fully simulated pools, one policy
      for any circuit, knob count and spec, one map estimator for every method.
    \item \textbf{The \rulename{} is a strong bar.} \todo{headline: does any learned explorer beat it on test?}
    \item \textbf{The reward must match the measure.} A one-step oracle that reads the truth still loses to the rule
      on \passfail{}.
    \item \textbf{A region carries what a point does not:} only 0--16\% of nominally passing designs survive every
      corner, and the nominal margin predicts which.
    \item \textbf{The map helps the designer choose the change:} Sonnet met all 3 achievable specs beyond the catalogue
      in both draws; a 14B open model met 3 of 4.
  \end{itemize}
\end{frame}

\begin{frame}{Limitations and next steps}
  \begin{columns}[T]
    \begin{column}{0.48\textwidth}
      \textbf{Limitations}
      \small
      \begin{itemize}
        \item Maps are scored at the typical corner.
        \item Explorers choose among stored pool designs (live only on one circuit).
        \item Below about 1\% passing, every method's map stays poor.
        \item The LLM result rests on 3 achievable specs.
      \end{itemize}
    \end{column}
    \begin{column}{0.48\textwidth}
      \textbf{Next steps}
      \small
      \begin{itemize}
        \item A robust map: one check per corner.
        \item A reward that matches \passfail{}, e.g.\ one that penalises predicting too wide a region.
        \item The designer with and without the map summary.
        \item A small model trained on the loop's circuit changes.
      \end{itemize}
    \end{column}
  \end{columns}
\end{frame}
